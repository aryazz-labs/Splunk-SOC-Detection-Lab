# Investigation: Multiple Failed Logons

## Summary
The detection returned three qualifying groups of Windows Security Event ID 4625 failures. The groups were observed on `Windows-11-Pro` and exceeded the configured threshold of five failures within a 10-minute bucket.

## Detection logic
The SPL groups Event ID 4625 events by 10-minute `_time` bucket, host, extracted target account and source IP. It returns groups with `failed_attempts >= 5`.

## Evidence observed
| Bucket time shown in Splunk | Host | Target account | Source address | Failed attempts |
|---|---|---|---|---:|
| 2026-11-15 01:10 | Windows-11-Pro | SOC_TestUser | 127.0.0.1 | 5 |
| 2026-11-15 04:30 | Windows-11-Pro | SOC_TestUser | 127.0.0.1 | 5 |
| 2026-11-15 07:00 | Windows-11-Pro | SOC_LabCreated | ::1 | 8 |

The screenshot displays three aggregated result rows. The expanded raw 4625 event separately shows logon type 2 (interactive) and the failure reason `Unknown user name or bad password.` That raw event is an example event and should not automatically be assumed to be one of every aggregated row above.

## Assessment
The search successfully identified repeated failed logon activity meeting its threshold. The displayed loopback addresses and lab account names are consistent with local test activity in this lab. The evidence does not identify an external attacker or establish malicious intent.

## Follow-up checks
1. Review the raw 4625 records for each bucket to verify logon type, target account and source address.
2. Check whether the attempts were generated by an authorized test or local user activity.
3. Correlate with Event ID 4624 and endpoint activity around each bucket.
4. If activity is unexpected, inspect the account status and review other authentication sources before containment.

## MITRE ATT&CK context
**Potential mapping:** T1110 – Brute Force. This is a behavioural mapping for repeated authentication failures, not a conclusion that a brute-force attack occurred.

## Disposition
**Lab detection validation; no confirmed compromise.**
